O que é uma função?

Uma função estabelece uma relação entre valores de entrada e valores de saída. No primeiro grau, ela pode ser representada por f(x) = ax + b, com a diferente de zero.

Como interpretar o gráfico

gráfico da função / imagem

O coeficiente a indica a inclinação da reta; o coeficiente b indica onde a reta cruza o eixo y.

Para lembrar
  • f(x) = ax + b
  • a ≠ 0
  • O gráfico é uma reta
